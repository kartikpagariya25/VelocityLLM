The problem

Traffic is never steady.

Real users arrive in waves. A batch size picked in advance is right for one moment and wrong for the next.

A fixed batch cannot bend.

Static batching serves a set number at a time and lets the rest queue. Latency climbs and deadlines slip.

Then the GPU runs out of room.

Nothing tells the scheduler to stop. Memory fills, requests fail and the whole server goes down with them.
